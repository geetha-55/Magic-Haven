# Magic-Haven
Magic Haven is a responsive restaurant website designed to offer an engaging user experience. Featuring a dynamic menu, high-quality images, and interactive elements, the site showcases detailed dish descriptions and customer reviews.
Features
Responsive Design: Adapts seamlessly to different screen sizes.
Dynamic Menu: Showcases a diverse selection of dishes with detailed descriptions.
Customer Reviews: Displays customer feedback to enhance credibility.
Special Offers: Highlights current promotions and discounts.
Smooth Scrolling: Ensures a smooth navigation experience.
Hover Effects: Interactive buttons and elements for better engagement.
Technologies Used
HTML: Structure and content of the website.
CSS: Styling and layout, including animations and responsive design.
JavaScript: Interactivity and dynamic content handling.
